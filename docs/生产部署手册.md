## 〇·一、生产首部署 vs 日常迭代 vs 镜像重建

| 场景 | 触发条件 | 走哪一节 |
|------|---------|---------|
| 首次部署 | 生产环境从未跑过 | **一、首次部署** |
| 日常迭代 | 仅源码变更，未改依赖/Dockerfile | **二、日常迭代** |
| 镜像重建 | 改了 requirements.txt / Dockerfile | **三、镜像重建** |

**判断口诀**：
- 只改了 backend 代码 → 二
- 加了 python 包 / 改了 Dockerfile → 三
- 第一次 / 空白新库 → 一

## 一、首次部署

### 1.1 准备工作（生产机 / Jupyter）

```bash
mkdir -p /data/work/cj/mythos-skills
```

上传 2 个文件到 `/data/work/cj/mythos-skills`（浏览器拖拽）：
- `mythos-skills-image-YYYYMMDD.tar` — 后端镜像
- `mythos-skills-code.tar.gz` — 代码包（含前端构建产物）

### 1.2 导入镜像

```bash
docker load -i /data/work/cj/mythos-skills/mythos-skills-image-YYYYMMDD.tar
```

### 1.3 解压代码

```bash
cd /data/work/cj/mythos-skills
tar -xzf mythos-skills-code.tar.gz
```

### 1.4 启动容器

```bash
ENV=THS_PRODUCT docker compose -f docker-compose.prod.yml up -d
```

### 1.5 初始化数据库

```bash
docker exec mythos-skills python -m app.init_db
```

## 二、日常迭代（仅源码变更）

### 2.1 开发机打包

```powershell
cd X:\workspace\mythos-skills
# 打包脚本（根据项目实际调整）
powershell -File scripts/build_and_package.ps1
```

### 2.2 上传到生产机

```
浏览器 → http://jupyter.10jqka.com.cn/tree
目录 → /data/work/cj/mythos-skills
```

### 2.3 解压并重启

```bash
cd /data/work/cj/mythos-skills
tar -xzf mythos-skills-code.tar.gz
docker restart mythos-skills
```

---

## 三、镜像重建（依赖或 Dockerfile 变更）

### 3.1 开发机构建

```powershell
docker build -t mythos-skills:YYYYMMDD -f backend/Dockerfile backend/ --no-cache
docker save -o mythos-skills-image-YYYYMMDD.tar mythos-skills:YYYYMMDD
```

### 3.2 上传并部署

```bash
# 生产机
docker load -i /data/work/cj/mythos-skills/mythos-skills-image-YYYYMMDD.tar
docker compose -f docker-compose.prod.yml down
docker compose -f docker-compose.prod.yml up -d
```
