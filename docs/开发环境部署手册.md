# mythos-skills 开发环境部署手册

> 最后更新: 2026-08-30 | 环境: TAYII_NOTEBOOK

## 〇、两种部署场景

| 场景 | 触发条件 | 走哪一节 |
|------|---------|---------|
| 首次部署 | 本地从未运行过 | **一、首次部署** |
| 日常迭代 | 仅源码变更，未改依赖/Dockerfile | **二、日常迭代** |
| 镜像重建 | 改了 requirements.txt / Dockerfile | **三、镜像重建** |

---

## 一、首次部署

### 1.1 构建镜像

```powershell
cd X:\workspace\mythos-skills
docker build -t mythos-skills:20260830 -f backend/Dockerfile backend/
```

### 1.2 启动容器

```powershell
docker compose -f docker-compose.dev.yml up -d
```

### 1.3 初始化数据库

```powershell
docker exec mythos-skills python -m app.init_db
```

### 1.4 前端启动

```powershell
cd frontend
pnpm install
pnpm dev
```

---

## 二、日常迭代（仅源码变更）

> 前提: `requirements.txt` 和 `Dockerfile` 未变更

### 2.1 后端

```powershell
# 源码通过 bind mount 自动同步，只需重启容器
docker restart mythos-skills
```

### 2.2 前端

```powershell
# Vite HMR 自动热更新，无需手动操作
# 如有构建产物需要更新:
cd frontend && pnpm build
```

---

## 三、镜像重建（依赖或 Dockerfile 变更）

### 3.1 重建镜像

```powershell
docker build -t mythos-skills:20260830 -f backend/Dockerfile backend/ --no-cache
```

### 3.2 更新容器

```powershell
docker compose -f docker-compose.dev.yml down
docker compose -f docker-compose.dev.yml up -d
```

### 3.3 验证

```powershell
# 健康检查
curl http://localhost:8000/api/health

# 前端
curl http://localhost:3000
```
