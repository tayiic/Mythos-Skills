# mythos-skills 开发环境手册

> 最后更新: 2026-08-30 | 环境: TAYII_NOTEBOOK (X:\ 虚拟盘)

## 一、环境要求

| 组件 | 版本 | 说明 |
|------|------|------|
| Docker Desktop | 最新稳定版 | Windows, X:\ 虚拟盘 |
| Node.js | 20+ | 前端开发 |
| Python | 3.12+ | 后端开发 |
| PostgreSQL | 16 | Docker 或本地 |
| pnpm | 8+ | 前端包管理 |

## 二、容器铁律

> 详见 [docs/_shared/DOCKER_IRON_LAWS.md](./_shared/DOCKER_IRON_LAWS.md)

1. **源码 bind mount** — 容器内代码必须来自宿主机目录挂载
2. **Runtime offline** — 容器运行后禁止 `pip install` / `npm install` / `apt install`

## 三、项目端口

| 服务 | 宿主机端口 | 容器内端口 |
|------|-----------|-----------|
| 后端 API | 8000 | 8000 |
| 前端 Dev | 3000 | 5173 |

## 四、快速启动

### 4.1 首次启动

```powershell
# 1. 构建镜像
docker build -t mythos-skills:latest -f backend/Dockerfile backend/

# 2. 启动服务
docker compose -f docker-compose.dev.yml up -d

# 3. 前端开发
cd frontend && pnpm install && pnpm dev
```

### 4.2 日常开发

```powershell
# 后端代码变更 → 重启容器即可（bind mount 自动同步）
docker restart mythos-skills

# 前端代码变更 → Vite HMR 自动热更新，无需手动操作
```

## 五、环境变量

| 变量 | 开发值 | 说明 |
|------|--------|------|
| ENV | TAYII_NOTEBOOK | 环境标识 |
| DB_HOST | localhost | 数据库地址 |
| DB_PORT | 5432 | 数据库端口 |
| DB_NAME | mythos-skills | 数据库名 |
| SECRET_KEY | (本地生成) | 从 .env 读取 |

## 六、数据库

```powershell
# 初始化数据库（首次）
docker exec mythos-skills python -m app.init_db

# 重置数据库
docker exec mythos-skills python -m app.init_db --clear
```

## 七、常见问题

### Q: Docker 容器无法启动
A: 检查端口是否被占用: `netstat -ano | findstr 8000`

### Q: 前端热更新不生效
A: 确保 Vite 配置中 `server.watch.usePolling: true`（Windows 跨文件系统需要）
