## 一、当前交付物

### 1.1 镜像

| 属性 | 值 |
|------|-----|
| 镜像名 | `mythos-skills:YYYYMMDD` |
| 构建命令 | `docker build -t mythos-skills:YYYYMMDD -f backend/Dockerfile backend/` |
| Build Context | `backend/` |
| 基础镜像 | `python:3.12-slim` |

### 1.2 代码包

| 属性 | 值 |
|------|-----|
| 文件名 | `mythos-skills-code.tar.gz` |
| 打包命令 | `powershell -File scripts/build_and_package.ps1` |
| 包含 | `backend/`（排除 `__pycache__`、`*.pyc`、`tests/`） |
| 前端 | 构建产物已写入 `backend/app/static/` |

### 1.3 导出镜像（跨机传输）

```powershell
docker save -o mythos-skills-image-YYYYMMDD.tar mythos-skills:YYYYMMDD
```

## 二、生产初始化链路

```
bootstrap_prod (ENV=THS_PRODUCT 守卫)
  ├─ 1. create_db         → 建库 mythos-skills（已存在则跳过）
  ├─ 2. sync_schema       → 数据库迁移
  ├─ 3. init_user         → 初始用户
  ├─ 4. init_seed_prod    → 初始数据
  └─ 5. verify_deploy     → 健康/数据/配置 验证
```

## 四、红线

- 镜像 tag 禁止 `:latest`（生产环境）
- 改库必 dry-run
- 容器 runtime 必须 offline
- 生产 ENV 不得随意修改
