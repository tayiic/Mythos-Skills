# mythos-skills 配置与测试规范

> 最后更新: 2026-08-30

## 一、配置体系

### 1.1 环境切换

配置按 `ENV` 环境变量自动切换。

| ENV | 环境 | 数据库 |
|-----|------|--------|
| `TAYII_NOTEBOOK` | 开发 | `localhost:5432/mythos-skills` |
| `THS_PRODUCT`（默认） | 生产 | `192.168.207.191:5433/mythos-skills` |

### 1.2 配置文件层级

```
.env              ← 本地敏感配置（不入库）
.env.dev          ← 开发环境默认值（入库存为参考）
.env.prod.example ← 生产环境示例（入库存为参考）
```

### 1.3 敏感信息策略

> 详见 [docs/_shared/SENSITIVE_INFO_POLICY.md](./_shared/SENSITIVE_INFO_POLICY.md)

| 级别 | 处理方式 | 示例 |
|------|---------|------|
| 允许暴露 | 写入 `.env.dev`，可提交 | `DB_HOST=localhost` |
| 环境变量注入 | 写入 `.env`，不入库 | `SECRET_KEY=xxx` |
| 严格禁止 | 任何文件不得包含 | 生产密码、API 密钥 |

## 二、测试规范

### 2.1 测试层级

| 层级 | 范围 | 工具 | 覆盖率要求 |
|------|------|------|-----------|
| 单元测试 | 函数/类 | pytest | ≥ 80% |
| 集成测试 | API 路由 | pytest + httpx | 核心路由 100% |
| E2E | 用户流程 | Playwright | 核心流程 |

### 2.2 运行测试

```powershell
# 后端
cd backend
pytest -v --cov=app --cov-report=term

# 前端
cd frontend
pnpm test
```

### 2.3 测试数据

- 测试数据通过 fixtures 提供，不依赖生产数据库
- Mock 外部服务（认证、第三方接口）
- 开发环境使用 mock-accounts 中的测试账号

### 2.4 质量门禁

- PR 合并前必须通过 CI 测试
- 覆盖率不得下降
- 新增代码必须有对应测试
- 禁止提交 `skip` / `xfail` 标记的测试

## 三、代码规范

### 3.1 Python

- 遵循 PEP 8
- 类型注解: 所有公共函数
- 行长度: 120 字符
- 工具: ruff (lint + format)

### 3.2 TypeScript/Vue

- `strict: true`
- 禁止 `any`（确有需要时注释理由）
- 工具: ESLint + Prettier

### 3.3 Git 提交

```
feat(scope): message
fix(scope): message
docs(scope): message
chore(scope): message
refactor(scope): message
test(scope): message
```
